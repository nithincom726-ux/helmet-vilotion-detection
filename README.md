# Helmet Violation Detection

## Project Overview
This project detects whether a motorcyclist is wearing a helmet using deep learning and computer vision techniques.

## Objective
To automatically identify helmet violations from traffic images and videos for improving road safety.

## Technologies Used
- Python
- Google Colab
- YOLO
- OpenCV
- Roboflow Dataset
  

## Input
Traffic image/video

## Output
Detection of riders with and without helmets and the processed output video.
